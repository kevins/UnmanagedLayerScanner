Unmanaged layer scanner

Finds the components of the managed solutions you choose that have an unmanaged layer on top, shows what changed, and deletes the layers you select. It runs in Edge with your own sign-in; nothing is installed in the environment.

Install

  1. Show the favourites bar (Ctrl+Shift+B).
  2. Drag this button onto the favourites bar: Unmanaged layers

If dragging does not work: create a new favourite named Unmanaged layers and paste this as its URL.

Use

  1. Open a page of the environment (for example https://contoso.crm.dynamics.com) or its Solutions page in the maker portal (make.powerapps.com).
  2. Click Unmanaged layers in the favourites bar, choose the managed solutions (and, if you like, object types or tables), then Scan.
  3. Filter any column, open a component's solution layers or its changes, export, or tick components and select Delete unmanaged layer.

Deleting an unmanaged layer cannot be undone. It is the same as "Remove active customizations" in the maker portal: the component goes back to what its managed solution defines. Each component is checked before and after, and a log of the removed changes can be downloaded.
